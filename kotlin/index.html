Kotlin - Codex

Prerequisites

Kotlin is a modern programming language developed by JetBrains, the company behind IntelliJ IDEA. Work on Kotlin began in 2010, and the language was officially released in 2016 as a concise, expressive, and safer alternative to Java. One of Kotlin’s biggest advantages is its full interoperability with Java, allowing developers to use existing Java libraries and frameworks seamlessly.

In 2017, Google announced official support for Kotlin on Android, and in 2019 it became the preferred language for Android app development. Kotlin primarily targets the Java Virtual Machine (JVM), but it also supports JavaScript and native compilation through Kotlin/JS and Kotlin/Native, making it a versatile cross-platform language for modern software development.

Entry Point

Unlike languages like Python, JavaScript or Ruby, Kotlin requires a entrypoint. A entrypoint is a function or a class from where the compiler starts to execute the codes. It will only run the codes inside the entrypoint. Just like C, C++ or Dart, Kotlin's entry point is,

fun main () {....}

And we will write codes inside this function.

Print Statement

Like every other High-Level Programming Languages, Kotlin has a print statement. The syntax is like this,

println ( "Hello World!" )

Point to remember, Kotlin Doesn't use ';' (SemiColon). It won't throw an error if you put one, but it just ignores it.

Variables

In Kotlin, there are 2 types of variables. There are mutable variables, means you can change their values in the runtime. And there are immutable variables, means you can't change their values in the runtime. The mutable variables are defined using var keyword, and the immutable variables are defined using val keyword. The syntax is,

<keyword> <variable> : <datatype> = <value>

Here is a example,

var greet : String = "Hello Kotlin!"

It's a mutable variable as it's defined with a var. So later in code if we do

greet = "Hi Everyone!"

It won't raise any error. But if we do

val name : String = "Codex"

Then assigning a value later in the code will raise an error

Kotlin: 'val' cannot be reassigned.

Kotlin also supports inferred datatype. Meaning it can determine a variable's datatype by it's value. While it's also a statically typed language. Means, a variable's datatype can't be changed in the runtime. So you don't have to mention the datatype of a variable like : <datatype> in the initialisation if you are giving it a value, it will determine the value automatically. You can simply do

var name = "Codex"

and Kotlin will define it as a String variable. You can also keep a variable uninitialised while defining. Meaning, you don't have to give it a value while defining. But then you have to mention the datatype. It's not necessary, and Kotlin will fallback on Any datatype if you don't mention, but it's a good practice to mention if the datatype if the variable is uninitialised.
